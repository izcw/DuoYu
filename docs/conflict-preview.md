# 同步更改的桌面预览

面板左侧是本组操作的本机版本，右侧是当前云端版本，不再显示“修改前”或逐字段编辑。支持页面、文件夹内容、工作区集合和快捷方式切换，以及放大和平移查看。每个版本右下角提供独立应用按钮。

直接使用 `LibraryGrid` 的只读模式，图标仍由 `WorkspaceFavicon` / `TextIcon` 绘制，文件夹仍使用 `FolderIconGrid`，日历、天气和便笺仍由桌面的组件分支渲染。未复制卡片 CSS。`WallpaperSurface` 从桌面背景组件中抽出为纯显示组件，两者共用图片、裁剪和遮罩样式；加载和全局背景状态仍只由原 `WallpaperBackground` 管理。每个预览独立应用对应版本的玻璃材质，复用原有材质 token 与聚焦层。

只读网格禁用拖动、尺寸调整、正文编辑、链接打开和右键管理，使用 `inert` 从键盘焦点中移除。预览中不会保存布局或修改业务数据，图片按原有缓存加载。

本机版本完整保留选中操作中的项目内容，并以当前云端其余数据作为上下文。布局使用与桌面相同的 `grid-layout.ts`，本机目标位置优先，其余项目需要让位时也纳入新提交；空间不足时阻止应用，避免隐藏项目。云端版本保留当前数据并将本组冲突标记处理。两种操作在执行前都会重新检查显示时的云端修订号。其他未处理冲突不受本次选择影响。

已验证类型检查、生产构建、同步集成测试，以及以下专项检查：

- `pnpm test:conflict-preview`：共用布局、本机优先、让位项目提交、云端模型不变、删除/溢出、文件夹内容，以及去除 Vue 代理后可保存 IndexedDB。
- `pnpm test:cloud:account-ui`：临时 Edge 扩展与专用测试 PostgreSQL，验证图标/文件夹/三个组件的共享渲染、页面切换与缩放、预览不写库、本机/云端应用、让位后的真实坐标，以及 JSON 导入。身份为模拟测试账号，不修改真实用户数据。
- `pnpm test:cloud:ui`：访客首页和登录面板冒烟检查。

历史 `test:library` 和 `test:widgets` 本次尝试未通过：脚本仍依赖已移除的收藏库轮盘入口，以及 `widget-1` 等旧示例组件。失败发生在旧夹具定位阶段，未将这两个脚本作为新界面通过的依据；它们需要另行迁移到当前桌面流程。
